## Why

The repository has no shared OpenSpec workflow or agent guidance, so contributors cannot reliably discover or follow a common spec-driven process. Initializing OpenSpec now establishes the shared skills and planning structure needed for future changes.

## What Changes

- Add the OpenSpec project structure and spec-driven configuration.
- Add shared agent skills for exploring, proposing, applying, updating, verifying, syncing, and archiving OpenSpec changes.
- Add the repository capability contract for using the shared OpenSpec workflow.

## Capabilities

### New Capabilities

- `openspec-initialization`: Provides the shared OpenSpec project structure and agent skills for spec-driven work.

### Modified Capabilities

## Impact

This is a repository tooling and documentation change. It adds OpenSpec configuration, shared agent skill instructions, and the initial capability specification; it does not change the runtime CLI or GitHub Actions behavior.
